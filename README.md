# Pixel Monsters — Battle Arena

A modular Tkinter pixel-art monster battle game.

## Requirements
- Python 3.9 or newer
- Tkinter (usually included with Python on Windows)

## Run
Open a terminal in this folder and run:

```bash
python main.py
```

## Project structure
- `main.py` — application entry point
- `pokemon_battle/config.py` — window dimensions, palette, and monster definitions
- `pokemon_battle/sprites.py` — embedded pixel-art sprite images
- `pokemon_battle/background.py` — procedural background generation
- `pokemon_battle/game.py` — battle interface, controls, and game logic

Use the arrow keys to navigate the battle menu and Enter to select. Press Esc to quit.
